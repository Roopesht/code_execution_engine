## Description

Set up a Docker container running llama.cpp with OpenAI-compatible API for providing AI feedback to students. Works offline, supports CPU/GPU, zero code changes for model switching.

---

## Goals

### Functional
- ✅ Run completely offline (no external API calls)
- ✅ Works on Windows, macOS, Linux
- ✅ Works with or without GPU (auto-detection)
- ✅ OpenAI-compatible API
- ✅ Fast startup (< 30 seconds)
- ✅ Easy model upgrades (no Docker rebuild)
- ✅ Multiple models supported
- ✅ Zero code changes when switching models

---

## Technology Stack

| Component | Choice | Rationale |
|-----------|--------|-----------|
| Runtime | llama.cpp | Fast, efficient, no dependencies |
| API | llama-server | OpenAI compatible, proven |
| Container | Docker | Portable, isolated |
| Models | GGUF | Quantized, fast loading |
| Quantization | Q4_K_M | Balance speed/quality |
| Default Model | Qwen2.5-Coder-3B | Small, fast, code-aware |
| Client SDK | OpenAI SDK | Standard, no custom code |
| Transport | HTTP | Simple, reliable |

## Architecture

### Docker Container

**Contains ONLY:**
- Ubuntu base image
- llama.cpp binary
- startup script
- runtime configuration

**Does NOT contain:**
- ❌ Python
- ❌ Node.js
- ❌ Ollama
- ❌ Models (mounted as volumes)

**Ports:**
- `8001` - OpenAI-compatible API

**Volumes:**
- `/models` - Model files
- `/config` - Runtime configuration
- `/cache` - KV cache
- `/logs` - Execution logs

**Health Check:**
- `GET /health` - Returns status and model info

## Dockerfile Specification

```dockerfile
FROM ubuntu:22.04

WORKDIR /app

# Install minimal dependencies
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    git \
    wget \
    ca-certificates \
    && rm -rf /var/lib/apt/lists/*

# Clone and build llama.cpp
RUN git clone https://github.com/ggerganov/llama.cpp.git && \
    cd llama.cpp && \
    make

# Copy startup script
COPY start.sh /app/start.sh
RUN chmod +x /app/start.sh

# Copy runtime config
COPY config/runtime.json /app/runtime.json

EXPOSE 8001

HEALTHCHECK --interval=30s --timeout=10s --start-period=40s --retries=3 \
    CMD curl -f http://localhost:8001/health || exit 1

CMD ["/app/start.sh"]
```

## Docker Compose

```yaml
version: '3.8'

services:
  llm-server:
    build:
      context: .
      dockerfile: docker/Dockerfile
    container_name: llm-server
    ports:
      - "8001:8001"
    volumes:
      - ./models:/models:ro
      - ./config/runtime.json:/app/runtime.json:ro
      - ./cache:/cache
      - ./logs:/logs
    environment:
      - MODEL_PATH=/models
      - CONFIG_PATH=/app/runtime.json
      - CACHE_PATH=/cache
      - LOG_PATH=/logs
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8001/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 40s
```

## API Endpoint

### OpenAI-Compatible Chat API

**Endpoint:** `POST /v1/chat/completions`

**Request:**
```json
{
  "model": "qwen",
  "messages": [
    {
      "role": "system",
      "content": "You are an experienced Python reviewer. Never reveal the correct solution. Only provide hints. Explain mistakes clearly. Praise correct approaches."
    },
    {
      "role": "user",
      "content": "Review this code: def foo(): return 42"
    }
  ],
  "temperature": 0.2,
  "max_tokens": 150,
  "top_p": 0.9
}
```

**Response:**
```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1720598400,
  "model": "qwen2.5-coder-3b",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Your solution correctly implements the function. Consider adding docstring and type hints."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 45,
    "completion_tokens": 23,
    "total_tokens": 68
  }
}
```

**Client Code (Python):**
```python
from openai import OpenAI

client = OpenAI(
    api_key="dummy",  # Not needed, local server
    base_url="http://localhost:8001/v1"
)

response = client.chat.completions.create(
    model="qwen",
    messages=[
        {
            "role": "system",
            "content": "You are an experienced Python reviewer."
        },
        {
            "role": "user",
            "content": "Review this code..."
        }
    ],
    temperature=0.2,
    max_tokens=150
)

print(response.choices[0].message.content)
```

## Error Handling

### Startup Errors

**Model file not found**
- Check: `/models/active.gguf` exists
- Verify: Model files mounted in docker-compose.yml
- Fix: Download/place model in `/models`

**CUDA/GPU not available**
- Gracefully falls back to CPU
- Logs: "GPU not available, using CPU"
- Performance: Slower but functional

**Insufficient memory**
- Error: "Failed to allocate {size}MB"
- Solution: Use smaller model or increase available RAM
- Fallback: Use 1.5B model instead of 3B

### Request Errors

All errors return appropriate HTTP status codes:
- **400** - Client error (bad request format)
- **408** - Timeout (generation took too long)
- **500** - Server error (model generation failed)
- **503** - Service unavailable (model not loaded)

See [LLM_ENDPOINTS_GUIDE.md](../LLM_ENDPOINTS_GUIDE.md) for complete error reference.
