## Description

Enable manual model selection via configuration. Users select desired model from available options in `docker-compose.yml` or `.env`, then rebuild Docker image. Support multiple models with manifest-based metadata.

---

## Goals

- ✅ Easy model selection via config (not hardcoded)
- ✅ Multiple models listed in manifest
- ✅ Simple model switching (edit config, rebuild, restart)
- ✅ Model validation and metadata
- ✅ Clear admin instructions
- ✅ Support model rollback

---

## Model Switching Flow

### Configuration-Based Model Selection

```
1. User decides to use Qwen2.5-Coder-1.5B instead of 3B
   ↓
2. Edit docker-compose.yml:
   environment:
     MODEL_NAME: qwen2.5-coder-1.5b
   ↓
3. Rebuild Docker image:
   docker-compose build llm-server
   ↓
4. Start container:
   docker-compose up -d llm-server
   ↓
5. Container startup:
   - Read MODEL_NAME env variable
   - Verify model file exists (in /models volume)
   - Load model
   - /health returns new model name
   ↓
6. Model switched successfully (rebuild time ~2 minutes)
```

## Configuration

### docker-compose.yml

**Before (hardcoded model):**
```yaml
services:
  llm-server:
    build:
      context: .
      dockerfile: docker/Dockerfile
    container_name: llm-server
    ports:
      - "8001:8001"
    environment:
      - EXECUTOR_API_KEY=${EXECUTOR_API_KEY}
    # ... rest
```

**After (configurable model):**
```yaml
services:
  llm-server:
    build:
      context: .
      dockerfile: docker/Dockerfile
      args:
        MODEL_NAME: ${LLM_MODEL_NAME:-qwen2.5-coder-3b-v2}
    container_name: llm-server
    ports:
      - "8001:8001"
    environment:
      - EXECUTOR_API_KEY=${EXECUTOR_API_KEY}
      - LLM_MODEL_NAME=${LLM_MODEL_NAME:-qwen2.5-coder-3b-v2}
    volumes:
      - ./lms/models:/models:ro
    # ... rest
```

### .env File

**File: `.env`**
```
LLM_MODEL_NAME=qwen2.5-coder-3b-v2
```

### Dockerfile

**Updated Dockerfile.executor.llm:**
```dockerfile
FROM ubuntu:22.04

ARG MODEL_NAME=qwen2.5-coder-3b-v2

WORKDIR /app

# ... build steps ...

ENV LLM_MODEL_NAME=${MODEL_NAME}

# Verify model is available in manifest
COPY lms/models/manifest.json /tmp/manifest.json
RUN python3 /scripts/validate_model.py ${LLM_MODEL_NAME}

# ... rest
```

## Model Switching Instructions

### For Users/Admins

**Step 1: Check Available Models**
```bash
cat lms/models/manifest.json | jq '.availableModels[]'
```

Output:
```
"qwen2.5-coder-3b-v2"
"qwen2.5-coder-3b-v1"
"qwen2.5-coder-1.5b"
"qwen2.5-coder-1.5b-v2"
```

**Step 2: Update .env**
```bash
echo "LLM_MODEL_NAME=qwen2.5-coder-1.5b" > .env
```

Or edit `.env` directly:
```
LLM_MODEL_NAME=qwen2.5-coder-1.5b
```

**Step 3: Rebuild Image**
```bash
docker-compose build llm-server
```

**Step 4: Restart Container**
```bash
docker-compose up -d llm-server
```

**Step 5: Verify**
```bash
curl http://localhost:8001/health | jq '.model'
```

Should show:
```json
{
  "id": "qwen2.5-coder-1.5b",
  "filename": "qwen2.5-coder-1.5b.gguf",
  "size_mb": 1600,
  "parameterCount": 1500000000
}
```

## Rollback Procedure

### Quick Rollback

**If new model has issues:**

```bash
# Switch back to previous model
echo "LLM_MODEL_NAME=qwen2.5-coder-3b-v2" > .env

# Rebuild and restart
docker-compose build llm-server
docker-compose up -d llm-server

# Verify
curl http://localhost:8001/health
```

## Model Validation

### Build-Time Validation

**Script: `scripts/validate_model.py`**

```python
#!/usr/bin/env python3

import json
import sys
from pathlib import Path

def validate_model(model_name):
    """Validate model exists and is not deprecated"""
    
    manifest_path = Path("/tmp/manifest.json")
    
    with open(manifest_path) as f:
        manifest = json.load(f)
    
    # Find model in manifest
    model = next(
        (m for m in manifest["models"] if m["id"] == model_name),
        None
    )
    
    if not model:
        print(f"❌ Model not found: {model_name}")
        print(f"Available: {', '.join(manifest['availableModels'])}")
        sys.exit(1)
    
    # Check if deprecated
    if model.get("deprecated"):
        print(f"⚠️  Model is deprecated: {model_name}")
        print(f"Recommended: {manifest['defaultModel']}")
        # Continue anyway, but warn
    
    # Check file exists
    model_file = Path(f"/models/{model['filename']}")
    if not model_file.exists():
        print(f"❌ Model file not found: {model_file}")
        sys.exit(1)
    
    print(f"✓ Model validated: {model_name}")
    print(f"  Size: {model['size_mb']}MB")
    print(f"  Params: {model['parameterCount']/1e9:.1f}B")
    print(f"  Context: {model['contextSize']}")

if __name__ == "__main__":
    model_name = sys.argv[1]
    validate_model(model_name)
```
