## Description

Create `/feedback` endpoint on executor that calls LLM service (port 8001) to provide AI feedback on failed code submissions. Leverages llama.cpp OpenAI-compatible API, no custom LLM logic.

---

## Endpoint Specification

### POST /feedback

**Purpose:** Get AI feedback on student's failed code

**Request:**
```json
{
  "language": "python",
  "exerciseId": "algo-sort",
  "studentCode": "def bubble_sort(arr):\n    return sorted(arr)",
  "failedTests": [
    {
      "name": "test_edge_case",
      "error": "AssertionError: expected [1,2,3], got [3,2,1]",
      "output": "..."
    }
  ],
  "compilerErrors": null,
  "staticAnalysis": [
    "Missing docstring",
    "No type hints"
  ]
}
```

**Response (200 OK):**
```json
{
  "status": "success",
  "feedback": "Your sorting implementation is good, but the test shows you're returning the original array instead of sorted. Check your return statement. Also, adding docstrings and type hints will make the code more professional.",
  "model": "qwen2.5-coder-3b",
  "tokens": {
    "prompt": 156,
    "completion": 45,
    "total": 201
  },
  "latency_ms": 234,
  "generatedAt": "2024-07-09T10:30:00Z"
}
```

## Error Responses

### 400 Bad Request
```json
{
  "status": "error",

```

### 503 Service Unavailable
```json
{
  "status": "error",
  "code": "LLM_UNAVAILABLE",
  "error": "LLM Service unavailable on port 8001",
  "details": {"llm_port": 8001, "timeout": 30}
}
```

### 500 Internal Server Error
```json
{
  "status": "error",
  "code": "LLM_ERROR",
  "error": "LLM generation failed: context length exceeded",
  "details": {"llm_error": "context length exceeded"}
}
```

## Request Format Details

### Required Fields
- `language` - "python", "javascript", or "react"
- `studentCode` - Student's submitted code (string)
- `failedTests` - Array of failed test objects

### Optional Fields
- `compilerErrors` - Compilation/syntax errors
- `staticAnalysis` - Linting/code quality issues
- `problemDescription` - Original problem statement (if available)
- `hints` - Optional: hints student has already received

### Input Constraints

**Student Code:**
- Max 2000 characters
- Required, non-empty

**Failed Tests:**
- Min 1 test
- Max 5 tests (to keep prompt small)
- Each test has: `name`, `error`, `output`

**Total Request:**
- Prompt will be ~400-800 tokens
- Include only failed tests, not passing ones

### Flow

```
POST /feedback
    ↓

    ↓
Build prompt (system + context)
    ↓

    ↓
/v1/chat/completions
    ↓
Parse response
    ↓

```

### HTTP Call to LLM

**Python Implementation Example:**
```python
import httpx

async def get_feedback(language: str, prompt: str) -> dict:
    """Call LLM service for feedback"""
    
    llm_url = os.getenv("LLM_SERVICE_URL")
    timeout = int(os.getenv("LLM_SERVICE_TIMEOUT", 30))
    
    payload = {
        "model": "qwen2.5-coder-3b",
        "messages": [
            {
                "role": "system",
                "content": SYSTEM_PROMPTS[language]
            },
            {
                "role": "user",
                "content": prompt
            }
        ],
        "temperature": 0.2,
        "max_tokens": 150,
        "top_p": 0.9
    }
    
    async with httpx.AsyncClient() as client:
        response = await client.post(
            f"{llm_url}/v1/chat/completions",
            json=payload,
            timeout=timeout
        )
        
        if response.status_code != 200:
            raise LLMError(f"LLM failed: {response.text}")
        
        return response.json()
```

## API Implementation Details

### Endpoint Handler

**FastAPI Endpoint:**
```python
from fastapi import APIRouter, HTTPException
from pydantic import BaseModel

router = APIRouter(prefix="/feedback", tags=["feedback"])

class FeedbackRequest(BaseModel):
    language: str  # python, javascript, react
    exerciseId: str
    studentCode: str
    failedTests: List[dict]
    compilerErrors: Optional[str] = None
    staticAnalysis: Optional[List[str]] = None

class FeedbackResponse(BaseModel):
    status: str
    feedback: str
    model: str
    tokens: dict
    latency_ms: float
    generatedAt: datetime

@router.post("/feedback", response_model=FeedbackResponse)
async def get_feedback(request: FeedbackRequest) -> FeedbackResponse:
    """Get AI feedback on failed code"""
    
    # Validate
    if request.language not in ["python", "javascript", "react"]:
        raise HTTPException(400, "Unsupported language")
    
    if not request.studentCode:
        raise HTTPException(400, "Student code required")
    
    if not request.failedTests:
        raise HTTPException(400, "At least one failed test required")
    
    # Build prompt
    prompt = build_prompt(
        language=request.language,
        code=request.studentCode,
        failed_tests=request.failedTests,
        compiler_errors=request.compilerErrors,
        static_analysis=request.staticAnalysis
    )
    
    # Call LLM
    try:
        llm_response = await get_feedback(request.language, prompt)
    except LLMError as e:
        raise HTTPException(503, f"LLM unavailable: {str(e)}")
    
    # Parse response
    feedback_text = llm_response["choices"][0]["message"]["content"]
    usage = llm_response["usage"]
    
    return FeedbackResponse(
        status="success",
        feedback=feedback_text,
        model="qwen2.5-coder-3b",
        tokens={
            "prompt": usage["prompt_tokens"],
            "completion": usage["completion_tokens"],
            "total": usage["total_tokens"]
        },
        latency_ms=calculate_latency(),
        generatedAt=datetime.utcnow()
    )
```

## Error Handling

### LLM Service Down

**Retry Logic:**
1. Try immediate call
2. On timeout: wait 2s, retry once
3. On failure: return 503 error

**Fallback:** None (hard fail, client should retry)

### LLM Generation Failed

**Scenarios:**
- Context length exceeded
- Model unloaded
- Invalid parameters

**Response:** 500 error with details

### Invalid Request

**Scenarios:**
- Missing required fields
- Invalid language
- Empty code

**Response:** 400 error with field details
